Markdown is a language we can use to make plain text look good.

# Headings or Headers

We create headings in Markdown using the hash symbol. We can also create subheadings with multiple hashes.

## Level two heading/header
### Level three heading
###### Level six heading

# Styling Characters

We typically use **bold** and *italics* to style characters when we type something. You can do both ***bold and italics*** like this.

We can also use underscores to __bold__ and _italicize_ words.

If you want to use stars, use only stars. The same is true for underscores. In other words, `be consistent.`

# Links

Markdown is a language that translates from plain text to another language called `HTML`. `HTML` is the language that _web pages_ are built with.

We can use links in our notes to other pages by using square brackets. `[]`
