## Peer Test/Review Code

There are two main parts to this: 1. testing code and 2. implementing any feedback.

## Testing Code 

You're going to send your code to at least one person to peer review.

Ask one person in the class who is willing to test your code. Send your .py file to them on Slack.

Once you've received a .py file from another classmate, this is the workflow:

1. Download the file and put it in your Python folder.
2. Open Zed and find the file.
3. Open Joplin. Copy and paste the testing template.
4. Run the code and enjoy it.
5. Once you're done, think about the feedback you're going to give and fill in the template.
6. Export it as a .pdf file and send it back to the person.

## Implementing any Feedback

You'll receive at least one .pdf for feedback.

Look over their feedback. Once you've done so, take their feedback into account and implement what you think is doable.
