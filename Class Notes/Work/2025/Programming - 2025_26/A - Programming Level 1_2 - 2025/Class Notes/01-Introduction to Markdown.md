# Styling Characters

We typically use **bold** and *italics* to style characters when we type something.

We can also use underscores to __bold__ and _italicize_ text.

You can ***bold and italicize*** characters.

If you like to use stars, use stars only. The same is true for underscores. `In other words, be consistent.`

# Escape Characters

The asterisk is a special symbol in Markdown. It's used to make characters bold.

\*\*I would like to put two stars here.

We can use an escape character to put in the literal symbol or character.

\_\_    \\\\

The escape character in Markdown is a backslash (\\).
