* Is your final product going on a screen?
	* What kind of screen is this going on?

* Click the blue new file button
* We'll generally use three different **size dimensions** in this class:
	* 4 **inches** by 6 **inches
	* 1920 **pixels** by 1080 **pixels**
	* 1080 **pixels** by 1920 **pixels**
* We will also generally use only one **resolution**:
	* 300 pixels per inch
	* Resolution is one measure of how big we can literally print out an image

## Layer

Layers allow us to group our ideas together in ways that make sense.

When we make a new layer, any changes we make in that layer don't affect the other layers.

Layers themselves are organized in a stack. This is found in the **Layer Panel** which is usually at the bottom right side of the screen.

Layers at the top of the panel are at the top of the "stack." Likewise, if they're at the bottom they will appear behind the other layers.

* create a new layer

## Brush tool

The brush is a great tool to start out with.

We can change it using the properties in the top bar. This changes depending on the tool we're using.

When we've selected the Brush tool, we can adjust things like colour, flow, size and shape of the brush, and opacity.

## Exporting

Once we're done with our work, we need to convert from Photoshop's format (\*.psd) to a format related to how we're wanting to show the file.

We'll generally use two formats:
* jpeg files (\*.jpg)
* png files (\*.png)

We export by using the menubar:
* `File`
	* `Export as...` or `Quick Export as PNG`
