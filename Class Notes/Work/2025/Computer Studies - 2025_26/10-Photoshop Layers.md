# Photoshop - Layers and Images

## Purpose

Get comfortable using layers and moving them around the stack.

## Instructions

1. Download the images that Mr. Ubial gives.
2. Create a new file
	1. Set the size to 6" wide x 4" tall
	2. Name it `Photoshop-Layers-1-Firstname Lastname`
3. Embed the photo
4. Starting from the *back* of the image, choose a section
	1. Choose they sky, or ground, for example
	2. Create a new layer
	3. Name it appropriately
5. Choose a colour
6. Paint over that part of the image
7. Choose the next thing in the foreground
8. Repeat steps 4-6

Do this for the remaining pictures, **then** when you're done, choose your own picture that you'd like and complete the task for your picture. **Note: please choose a "high resolution" image.**

After you're finished, I'll show you how to export the Photoshop files to a jpg.

## Deliverable

3 images:
* named `Photoshop-Layers-number-Firstname Lastname.jpg`
* exported as `.jpg`
