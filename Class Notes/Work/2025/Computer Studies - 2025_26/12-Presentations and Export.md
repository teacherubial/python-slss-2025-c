## Exporting in Photoshop

`.psd` files are generally for working on.

When we want to share files with other people, we need to export them.

For the layers activity, we'll export our `.psd` files to `.jpg`.

1. File
2. Export as
3. Set the file type to `jpg`
4. Set the quality accordingly
5. Choose a place where you want to save it and give it a descriptive filename.
