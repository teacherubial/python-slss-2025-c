# Photoshop - 4 Adjustment Layers

## Big Questions

When adding one image to another, how can we match them as close as possible?

## Layers Again, AGAIN!?

Yes, again. To create a new Adjustment Layer, we click the button that looks like a circle that's half dark and half light.

When we create a new adjustment layer, it affects all layers under it. It also creates a layer mask for that particular adjustment.

The example we looked at in class looks at the **Color Balance** adjustment layer.

More information about how to use the Color Balance adjustment layer are available [here](https://www.photoshopbuzz.com/how-to-copy-mask/).

## Using the **Layer Mask**

We can apply the Adjustment Layer to specific parts of the image by using layer masks.

After we've made the adjustments in the Property panel, we *invert* the mask with **Cmd + i**.

Then, using the brush tool set to the colour white, we can paint into the layer mask to apply the adjustment to the places we paint.

## Linking the adjustment layers

Adjustment layers affect all layers below it in the *layer stack*. Sometimes we want it to work for *only one layer*. To do this, we need to link the layer.

If you want to link the adjustment layer, in the layer panel, put your mouse in between the two layers, hold the *Option* key, then click.
