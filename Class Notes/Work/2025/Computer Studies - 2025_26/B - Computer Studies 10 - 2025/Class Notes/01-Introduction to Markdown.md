We create headings in Markdown using the hash symbol. We can create subheadings using multiple hash symbols.

### Level three heading

# Styling Characters

We typically use **bold** and *italics* to style characters.

We can also use underscores to create __bold__ and _italicized words_. 

We can use both to do ***bold and italics*** to a set of characters.

If you like to use stars, use only stars. If you like to use underscores, use only underscores. `In other words, be consistent.`

# Links

Markdown is a language that translates from plain text to another language called `HTML`. `HTML` is a language used to make web pages.

We use brackets to create links to other resources. `[]`
